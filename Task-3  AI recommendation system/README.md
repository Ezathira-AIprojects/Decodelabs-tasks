# 🛒 AI-Based Product Recommendation System

An AI-based Product Recommendation System that suggests similar products to users using Content-Based Filtering. 
Developed with Python, Machine Learning, and Streamlit during the Decode Labs AI Internship.

---

## 📌 Features

- Personalized product recommendations based on product similarity
- Content-Based Filtering
- Cosine Similarity Algorithm
- Interactive Streamlit Dashboard
- Product Details
- Dataset Analytics
- Payment Method Analysis
- Order Status Visualization
- User-Friendly Interface

---

## 🛠 Technologies Used

- Python
- Pandas
- Scikit-Learn
- Streamlit
- CountVectorizer
- Cosine Similarity

---

## 📂 Dataset

The dataset contains e-commerce transaction data including:

- Order records
- Product information
- Customer details
- Payment methods
- Coupon usage
- Referral sources
- Order status
- Total purchase amount

Dataset Size:
- 1200+ orders
- 7 unique products

